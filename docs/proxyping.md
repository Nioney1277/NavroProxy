# /navro proxyping

`/navro proxyping` 查看自己的代理处理耗时；`/navro proxyping <player>` 查看指定在线玩家。控制台需要指定玩家。

- 上行：客户端输入进入代理处理函数，到该处理函数完成。
- 下行：后端数据进入代理处理函数，到该处理函数完成。
- 每个方向独立保留最近 256 次，显示平均、P95、最大值和样本数。RakNet 按包，NetherNet 按 Bedrock 批次统计。
- 客户端 RTT：最近一个收到有效回复的代理自发延迟标记的往返时间；没有样本时显示“暂无样本”。

代理处理耗时不包含处理函数外的网络传输、前端进程 IPC、发送队列等待与客户端渲染；不能据此声称端到端单向转发延迟。使用单调时钟计时，不从 RTT 猜测单向耗时。

代理权限为 `navro.proxyping`，桥接权限为 `navrobridge.proxyping`，默认 OP。代理与桥接命令来源均支持此子命令。默认 `command-source: proxy` 只需更新、重启代理；桥接来源还需更新桥接插件并使其重新加载。
